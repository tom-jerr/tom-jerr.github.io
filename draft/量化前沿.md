## 2025-2026 最新 LLM 量化技术论文综述

我按 **Weight-Only PTQ**、**Weight-Activation Joint**、**KV Cache**、**Outlier 处理**、**低秩补偿与极端压缩** 五个方向做了系统梳理。每篇论文都标注了**核心问题**、**方法创新**和**关键结果**。

### 一、Weight-Only Post-Training Quantization

#### 1. FASQ: Flexible Accelerated Subspace Quantization (2026-04)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 传统标量量化（RTN/GPTQ/AWQ）局限于固定比特宽度（8/4/3-bit），只能提供**离散的压缩点**（如 50%、37.5%、25%），且通常需要校准数据。 |
| **Method** | 将 **Product Quantization (PQ)** 引入 LLM 权重矩阵：把权重矩阵沿某一维度切分为 $N_{ss}$ 个子空间，每个子空间独立做 K-means 聚类，存储 codebook（centroids）和 uint8 索引。通过调节 **sub-vector size** 和 **codebook cardinality** 两个参数，实现 **27%–49% FP16 大小的连续压缩空间**。推理时直接在压缩表示上计算，不做反量化重建。 |
| **Kernel 设计** | Decode：LUT-free direct-compute GEMV，每个 thread 在寄存器内直接做 centroid dot-product 累加，无需 shared-memory LUT；Prefill：output-stationary double-buffered LUT GEMM，split-K 并行。 |
| **关键结果** | Llama-3-8B 上 37–42% 模型大小达到 **67.1–67.7 avg accuracy**（超过 4-bit GPTQ/AWQ）。RTX 3090 上 decode **45.2 tok/s**（eff. 4-bit，2.56× 内存压缩）和 **51.8 tok/s**（eff. 3-bit，2.80×），**均超过 FP16 的 43.9 tok/s**。是**唯一一个 decode 速度超过 FP16 的压缩方法**。 |

**核心洞察**：PQ 的索引查找模式在 decode 阶段反而比 scalar 量化的 unpack+dequant+GEMM 更快，因为内存带宽减少 4×，且不需要写回 FP16 中间结果。

#### 2. HeRo-Q: Hessian Robust Quantization (2026-01/06)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | PTQ 中 **"low error, high loss" 悖论**：量化误差（MSE）很小，但模型损失（perplexity/accuracy）却大幅上升。根因是 Hessian 矩阵的少数高曲率方向对扰动极度敏感。 |
| **Method** | 在量化前对权重空间做 **Hessian-conditioned coordinate transformation**：(1) 从校准数据估计 activation-induced Hessian 对角线；(2) **Diagonal smoothing**（$\mathbf{D}_\alpha = \text{diag}(\|\mathbf{h}\|^{\alpha/2})$）抑制高曲率方向；(3) **Learnable orthogonal rotation**（通过 Cayley transform 参数化）将量化噪声从敏感方向重分布到低曲率方向。变换后调用标准 PTQ backend（GPTQ/AWQ/RTN）。 |
| **关键结果** | Llama3-8B **W3A16** 下 GSM8K accuracy 达到 **70.15%**（避免激进量化时的逻辑崩溃）；在 W4A8 和 W3A16 下均**稳定优于 GPTQ、AWQ、SpinQuant**。 |

**核心洞察**：不是最小化量化误差本身，而是最小化 **curvature-weighted loss**（$\Delta L \approx \Delta \mathbf{w}^T \mathbf{H} \Delta \mathbf{w}$），即让误差避开 Hessian 的大特征值方向。

#### 3. BDQ: Bidirectional Diagonal Quantization (2026-05)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | Activation outliers 导致低比特量化性能退化；现有方法（SmoothQuant、QuaRot 等）做线性变换后，权重和激活仍表现出**集中的 outlier 模式**。 |
| **Method** | 提出新度量 **Flatness** 来量化 outlier 分布的"平坦度"：Flatness 越高，outlier 越集中，量化越难。基于此推导**理论最优解**，提出 **BDQ**：通过**学习的双向对角操作**（learned diagonal transformations）在矩阵维度间**分散 outlier 幅度**，使分布更均匀。 |
| **关键结果** | LLaMA-3-8B **W4A4** 精度下降 **< 1%**；DeepSeek-R1-Distill-LLaMA-70B **W2A4KV16** 下与 SOTA 相比性能差距减少 **39.1%**。 |

---

#### 4. ButterflyQuant: Ultra-Low-Bit via Learnable Orthogonal Butterfly Transforms (2025-09)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 固定旋转（QuIP#/QuaRot）不能适应特定模型；学习旋转（SpinQuant）需要 $O(n^2)$ 参数和 $O(n^3)$ 操作，开销巨大。 |
| **Method** | 用 **Givens parameterization**（一系列 2×2 旋转矩阵的 butterfly 结构）来参数化正交变换。保证正交性 by construction，同时支持高效的数据驱动学习。桥接了"固定旋转"和"学习旋转"之间的 gap。 |
| **关键结果** | 在 **2–3 bit** 超低比特设定下优于 QuIP# 和 SpinQuant，且参数量和计算量远低于 SpinQuant。 |

---

#### 5. HARP: Hadamard-Preconditioned Adaptive Rotation Processor (2026-05)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 极端低比特（2–3 bit）量化需要更好的 incoherence processing；现有固定 Hadamard 或随机正交矩阵不能针对具体模型优化。 |
| **Method** | 在 PTQ 校准循环中拟合一个 **Hadamard-preconditioned adaptive rotation**。以 Hadamard 为 backbone，通过校准数据学习微调旋转。严格保持正交性（不改变 FP16 模型），作为 QuIP# 风格 pipeline 的 **drop-in replacement**。 |
| **关键结果** | 作为可重用 processor 模块，在 2–3 bit 极端压缩下提升精度，且保持与现有后端（trellis codes, lattice codebooks）的兼容性。 |

---

#### 6. GlowQ: Group-Shared Low-Rank Approximation (2026-04)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 低秩补偿量化误差（LQER/QERA/ASER）时，每层独立插入 $(A_i, B_i)$ 模块，导致：(1) 相同输入的模块重复计算 $B_i X$；(2) 内存流量增加；(3) GPU 内存膨胀。 |
| **Method** | 将**共享相同输入的模块**（如 Q/K/V 投影、MLP 的 gate/up）分组，每组学习**一个共享的右因子 $B_{\text{shared}}$** 和各自的左因子 $\{A_i\}$。推理时 $R := B_{\text{shared}} X$ 只算一次，组内所有模块复用。提出 **covariance-aligned objective** 让子空间对齐数据偏好方向，并用 QR-reduced randomized SVD 高效求解。 |
| **关键结果** | 平均减少 **TTFB 5.6%**，提升吞吐量 **9.6%**；WikiText-2 PPL 降低 0.17%，下游 accuracy 提升 0.42 pp。Selective 变体 GlowQ-S 进一步削减 TTFB **23.4%**，吞吐量提升 **37.4%**，精度损失仅 0.2 pp。兼容 INT2/3/4、MXFP4/6、NVFP4。 |

### 二、Weight-Activation Joint Quantization

#### 7. OffQ: Taming Structured Outliers by Offsetting (2026-06)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | Activation outliers 限制低比特量化，尤其是 **W4A4KV4 端到端量化**（weight + activation + KV cache 全 4-bit）。 |
| **Method** | (1) 用 **top-1 PCA** 识别 activation 中的低维 outlier 子空间；(2) 通过旋转将高幅度 activation **集中到 1 个 channel**；(3) 用 **Hadamard rotation** 将 outlier energy 转化为 **group-wise offsets**；(4) 将 offsets 吸收到标准低比特量化的 **zero-point** 中。全程保持 uniform-grid、uniform-precision，无需混合精度。 |
| **关键结果** | Qwen2.5-72B W4A4KV4 下 PPL **4.29**（FP16 基线 3.9）；Llama3-8B W4A4KV4 下 PPL **6.98**（FP16 6.1）。在 Qwen2.5 全系列（1.5B–72B）和 Llama3 系列上均优于 QuaRot/SpinQuant/ResQ。 |

#### 8. LBLLM: Lightweight Binarization via Three-Stage Distillation (2026-04)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 1-bit weight 量化（binarization）精度损失大，且现有方法依赖混合精度或旋转矩阵，硬件效率低。 |
| **Method** | **W(1+1)A4**：权重做 1-bit binarization（带 fine-grouping），activation 保持 4-bit。通过三阶段蒸馏（logit distillation → feature distillation → self-distillation）恢复精度。移除对混合精度和旋转矩阵的依赖。 |
| **关键结果** | 在 1-bit weight + 4-bit activation 的极端压缩下，通过蒸馏达到接近更高比特方法的精度，且硬件效率更高。 |

### 三、KV Cache Quantization

#### 9. SAW-INT4: System-AWare 4-Bit KV-Cache (2026-04)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 现有 KV cache 压缩方法（VQ、KMeans、Hessian-aware）在**真实 serving 系统**中常违反约束：paged memory layout、regular memory access、fused attention execution，导致实际部署收益远低于论文报告。 |
| **Method** | 系统级 co-design：(1) **token-wise INT4** 量化（per-token per-head scale + zero-point）；(2) **block-diagonal Hadamard rotation (BDR)** 处理 channel-wise outlier；(3) **fused rotation-quantization kernel** 直接集成到 paged KV-cache layout，零可测端到端 overhead。 |
| **关键结果** | 在真实 serving 约束下，**简单 BDR + INT4 即可恢复 naive INT4 丢失的几乎所有精度**；更复杂方法（VQ、Hessian-aware）在考虑 serving 兼容性后仅提供**边际增益**。证明 KV cache 压缩本质上是**系统 co-design 问题**。 |

---

#### 10. TurboAngle: Near-Lossless KV Cache via Uniform Angle Quantization (2026-03)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | KV cache 压缩需要更高精度、zero calibration、且对每层/每头的异构性敏感。 |
| **Method** | 在 **Fast Walsh-Hadamard domain** 中量化角度：随机 $\pm1$ 对角旋转使连续元素对在单位圆上均匀分布，从而可用 uniform angle quantizer。提出 **per-layer early-boost**：独立配置每层 K 和 V 的 codebook 大小，对关键层分配更高精度。附加 **norm quantization**（K 用 8-bit linear norm，V 用 4-bit log-space norm）。 |
| **关键结果** | 7 个模型（1B–7B）中 **4 个实现 lossless compression（ΔPPL ≤ 0）**，2 个 near-lossless（ΔPPL ≤ 0.002）。Mistral-7B 上 **6.56 total bits**，ΔPPL = **+0.0014**。发现 critical layers、bottleneck type（K-dominated vs V-dominated）、甚至 negative-transfer layers（增加精度反而降质）都是**模型特定**的。 |

### 四、Activation Outlier 处理与动态精度

#### 11. DynamicPTQ: Mitigating Activation Quantization Collapse (2026-06)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | 4-bit activation 量化在某些层会"崩溃"（精度骤降），现有方法只关注层内分布统计，忽略了**残差流动力学（residual-stream dynamics）**：历史残差信息在低比特量化后被破坏，导致层间误差累积。 |
| **Method** | 提出 **Jump Ratio** 和 **Historical Feature SNR** 两个指标，从 residual-stream 视角识别 4-bit activation 不稳定的层。对这些敏感层使用 **8-bit activation**，其余保持 4-bit。 |
| **关键结果** | 与 SmoothQuant/Atom/KIVI 等基于分布统计的方法**互补**，从网络深度维度解决不稳定性。在保持 W4A4 整体效率的同时避免量化崩溃。 |

### 五、Specialized Formats 与误差分析

#### 12. Decomposing MXFP4 Quantization Error for RL (2026-05)

| 维度 | 内容 |
|------|------|
| **解决什么问题** | MXFP4（E2M1，microscaling block size 32）和 NVFP4 的 non-uniform grid 与小 block size 改变了传统 INT 量化的动态，需要理解其误差构成。 |
| **Method** | 将 MXFP4 量化误差分解为三个部分：**reducible bias**（可通过校正恢复）、**recoverable deadzone**（可通过 dithering 或微调恢复）、**irreducible floor**（格式固有下界）。提出针对性校正策略，与上游的旋转/平滑方法互补。 |
| **关键结果** | 为 MXFP4/NVFP4 的推理和训练（尤其是 RL 场景）提供了误差分析和校正框架。MR-GPTQ（微旋转融合到 GPTQ 中）配合 CUTLASS-based kernel（QuTLASS）实现高效推理。 |

### 技术趋势总结

| 趋势 | 说明 |
|------|------|
| **从标量到向量/产品量化** | FASQ 用 PQ 打破固定 bit-width 限制，实现连续压缩空间，且推理速度反超 FP16。 |
| **从最小化误差到最小化损失** | HeRo-Q 用 Hessian 条件化直接优化 loss landscape，解决 "low error, high loss"。 |
| **从固定旋转到可学习结构化旋转** | ButterflyQuant、HARP 用 Givens/Hadamard-preconditioned 旋转，兼顾理论保证与模型适应性。 |
| **从分布统计到动力学视角** | DynamicPTQ 从 residual-stream dynamics 识别敏感层；OffQ 从 outlier subspace 结构出发做 offsetting。 |
| **系统 co-design 成为 KV cache 核心** | SAW-INT4 证明在真实 serving 约束下，简单 BDR+INT4 优于复杂方法，强调 fused kernel 和 paged layout 兼容性。 |
| **低秩补偿从 per-layer 到 group-shared** | GlowQ 用输入共享组的低秩复用，将补偿开销从 $O(L \cdot r \cdot d)$ 降到 $O(G \cdot r \cdot d)$。 |
